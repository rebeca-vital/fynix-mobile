# FYNIX

Aplicativo mobile desenvolvido com React Native e Expo para auxiliar usuários no acompanhamento de gastos, visualização de saldo e organização financeira.

## Sobre o Projeto

O FYNIX foi desenvolvido como projeto acadêmico da disciplina de Desenvolvimento para Dispositivos Móveis.

A proposta do projeto foi criar uma MVP (Minimum Viable Product) de um aplicativo de controle financeiro pessoal, aplicando conceitos de desenvolvimento mobile, usabilidade e consumo de APIs.

## Funcionalidades

- Login de usuário
- Navegação entre telas
- Dashboard financeiro
- Histórico de gastos
- Perfil do usuário
- Configurações
- Dark Mode
- Integração com API utilizando Axios
- Interface responsiva

## Como Executar

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npx expo start
```
