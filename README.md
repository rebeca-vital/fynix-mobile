# FYNIX Finance

Aplicativo mobile desenvolvido com React Native e Expo para auxiliar no controle financeiro pessoal.

## Funcionalidades

* Visualização de saldo disponível
* Histórico de gastos
* Objetivos financeiros
* Perfil do usuário
* Configurações do aplicativo
* Suporte aos modos Claro e Escuro (Dark Mode)

## Tecnologias utilizadas

* React Native
* Expo
* Expo Router
* TypeScript
* Axios

## Como executar

```bash
npm install
npx expo start
```

## Status do projeto

Projeto acadêmico em desenvolvimento, com foco em aprendizado de desenvolvimento mobile utilizando React Native e Expo.
